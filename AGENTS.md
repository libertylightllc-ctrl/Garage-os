# GarageOS — Agent Instructions

## What we're building
Phase 1 MVP of GarageOS: a GCC garage operating system. **UAE only.**
WhatsApp-first. AI proposes, humans confirm. Read `docs/GarageOS-Technical-Spec.md`
and `docs/GarageOS-GCC-Master.md` before making decisions. The buildable contract
is the Technical Spec; the Master Plan is strategy.

## Stack (do not deviate without asking) — free tiers chosen
- Next.js 16 (App Router) + TypeScript + Tailwind v4 + shadcn/ui
- Node API routes (Next route handlers)
- **PostgreSQL on Supabase free tier** (DB + object Storage), Prisma ORM
- **Auth.js (NextAuth v5)** — staff only; customers are passwordless (see rules)
- Anthropic API for AI; WhatsApp Business Cloud API (Meta) for messaging
- Tests: Vitest (unit) + Playwright (e2e)
- i18n/RTL: next-intl

## Rules
- Work in SMALL steps. After each step: it must run, be committed, have a test.
- Never invent a different library when the spec names one.
- All money is Prisma `Decimal`, NEVER `Float` (accounting integrity).
- Staff (4 roles: OWNER/ADVISOR/TECH/ACCOUNTANT) are auth Users; Customers are a
  separate passwordless, phone-keyed model — customers never install an app / log in.
- AI intake is propose-confirm: it writes a `Booking` row, never auto-creates a
  JobCard. A human advisor confirms.
- Every AI call must write an `AiEvent` row (incl. `model`) for usage metering.
- Invoice keeps `clearanceStatus` + `qrPayload` from day one (KSA hook); invoice
  lines are a SNAPSHOT; numbering is gapless & per-garage (`@@unique([garageId, number])`).
- Accounting is zero-entry: `LedgerEntry` rows are generated by services, never by hand.
- Copilot is read-only and ALWAYS scoped to the owner's `garageId` — no raw SQL.
- Webhooks (WhatsApp, later Stripe) are idempotent — dedupe on provider event id.
- Ask before: installing a new dependency, changing the schema, or touching auth/payments.
- Keep screens to max 3 primary actions. Mobile-first. i18n/RTL infrastructure is
  wired from Step 1 (Arabic + English, RTL correct); translations land progressively.
- Secrets live in `.env` (git-ignored) — never in code, never committed.
